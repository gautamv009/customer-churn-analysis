# Customer Churn Analysis

## Overview

Customer churn refers to customers discontinuing a company's services. Understanding churn behavior helps businesses identify factors that influence customer retention and customer satisfaction.

This project performs Exploratory Data Analysis (EDA) on a customer churn dataset to understand customer characteristics, service usage patterns, and factors associated with churn. The analysis focuses on identifying trends through data cleaning, visualization, and insight generation using Python.

---

## Problem Statement

Customer churn is a significant challenge for subscription-based businesses because losing customers directly affects revenue and growth.

The objective of this project is to explore customer data and identify patterns associated with churn using exploratory data analysis techniques.

---

## Objectives

- Explore customer demographics and service usage patterns
- Analyze factors associated with customer churn
- Identify trends through exploratory data analysis
- Generate insights from visualizations and customer data

## Key Insights

- Customers with month-to-month contracts exhibit higher churn rates.
- Customers with shorter tenure are more likely to discontinue services.
- Senior citizens show relatively higher churn behavior compared to non-senior customers.
- Customers using electronic check payment methods demonstrate increased churn rates.
- Long-term contracts are associated with better customer retention.
